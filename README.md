# Echo Nomads

A highly atmospheric, post-apocalyptic Web3 survival and exploration game deployed on Base Mainnet.

## Game Overview
In **Echo Nomads**, players navigate a desolate yet serene world, managing essential survival resources while uncovering ancient relics and broadcasting their resonance on-chain.

### Core Mechanics
- **Resource Management**: Maintain three vital thresholds.
  - **Energy**: Keep moving, but remember every step drains your power.
  - **Water**: You must constantly search for droplets to retain hydration.
  - **Resonance**: Keep broadcasting to gather echoes and remain sane against the silence.
- **Relic Hunting**: Dig for rare, forgotten fragments of the old world that boost you on your journey.
- **On-chain Chronicles**: Record your longest pilgrimages directly to the Base blockchain. High scores are indexed as global ranks.

## The World
The world of Echo Nomads is rendered dynamically using adaptive distance fog, parallax structures, and atmospheric effects. Survive as long as you can in the wasteland against the odds.

## Agent Orchestrator (ERC-8004)
Echo Nodmads employs a modular AI agent to control nomadic exploration patterns. The agent card is openly accessible at `/.well-known/agent-card.json`.

*Note: Production URLs, API endpoints, and smart contract connection environments are securely provided by the Echo Nomad system orchestrator and excluded from public repository templates.*
